Paso 1 — df.isnull()
Convierte cada celda en True si es NaN, False si tiene valor:
 f_0    f_1    f_2
   False  True   False
   True   False  False
   False  False  False

Paso 2 — .sum()
Suma por columna. Como True=1 y False=0, cuenta los NaN de cada columna:
f_0    1
f_1    1
f_2    0
dtype: int64

El resultado es una Serie indexada por nombre de columna, en el mismo orden que df.columns. 

En resumen:
La función usa df.isnull() para detectar celdas nulas (devuelve un DataFrame booleano donde True = NaN) 
y luego .sum() para sumar los True por columna, ya que True equivale a 1 y False a 0. El resultado es una Serie 
de pandas indexada por el nombre de cada columna con el conteo de nulos.
